# Todo App

A simple and responsive Todo application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using Local Storage
- Persist tasks after page refresh
- Clean and user-friendly UI
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure

    todo/
    ├── images
    ├── index.html
    ├── style.css
    ├── script.js
    └── README.md

## Getting Started

### 1. Clone the Repository

    git clone <https://github.com/Amanv-08/todo-app-js.git>

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Application

Open `index.html` in your browser or use the Live Server extension in VS Code.

## How to Use

1. Enter a task in the input field.
2. Click the Add button to create a task.
3. Mark a task as completed when finished.
4. Delete tasks you no longer need.
5. Refresh the page to verify that tasks remain saved in Local Storage.

## Learning Objectives

- Learn DOM manipulation using JavaScript.
- Handle user interactions and events.
- Implement task management functionality.
